# 永無島三部曲｜國小國語文遊戲式線上測驗總入口

結合彼得潘永無島冒險劇情的**國小國語文（第一至第三學習階段：低、中、高年級）**遊戲式線上測驗入口網站。
視覺與互動完全沿用三部曲的「日系 RPG × 視覺小說（Visual Novel）」設計規範，採 **100dvh 單一螢幕無捲軸** 響應式版面設計。

## 連結之三部曲測驗網站

1. **第一部（低年級｜第一學習階段）**：[《永無島的初次飛翔：星空、仙塵與遺失的玩具》](https://grethel1988-ai.github.io/neverland-flight-1/)
2. **第二部（中年級｜第二學習階段）**：[《永無島的失落篇章：公主、謊言與隱密樹屋》](https://grethel1988-ai.github.io/neverland-lost-chapter-2/)
3. **第三部（高年級｜第三學習階段）**：[《永無島的黃昏：影子、時鐘與不沉之船》](https://grethel1988-ai.github.io/neverland-twilight-3/)

## 四大頁籤功能

- **🏰 三部曲入口**：三部曲傳奇總覽卡片（含學習階段、生命值圖示、劇情簡介、核心指標標籤、4 位同行夥伴頭像預覽與一鍵出發按鈕）＋底部夥伴打字機導覽對話框。滑鼠移過卡片可動態預覽該部曲專屬背景與色調氛圍。
- **📖 故事與關卡**：切換低、中、高年級三部曲，檢視完整「前情提要」、挑戰難度設定，並可點擊各關卡卡片預覽場景與角色過場對話。
- **🧚 角色圖鑑**：收錄全系列 13 組登場角色（彼得潘、奇妙仙子、溫蒂、約翰、麥克、虎蓮公主、史萊特利、圖特斯、雙胞胎、庫比、虎克船長、史密、滴答鱷魚），支援分類篩選、試聽「登場招呼／答對誇獎／答錯鼓勵」台詞，以及奇妙仙子「生氣發紅光」特效切換。
- **🎮 玩法與課綱指標**：
  - **遊戲機制與五大互動題型**：介紹 25 / 40 / 50 題三種難度、小熊軟糖／勇氣羽毛／航海羅盤生命值、夥伴陪考與防弊回饋、榮譽證書列印，以及標楷體五大題型（選擇、配對、填空、分類、排序、閱讀題組）互動預覽台。
  - **108 課綱國語文能力指標對照表**：完整列出第一至第三學習階段共 33 項學習表現指標與對應關卡，方便教師與家長查閱。

## 本地執行

直接開啟 `index.html`，或於本目錄啟動本地伺服器：

```powershell
python -m http.server 8080
```

接著在瀏覽器開啟 `http://localhost:8080`。

## 部署至 GitHub Pages

1. 將本資料夾推送至獨立的 GitHub Repository（例如 `neverland-trilogy`）。
2. 於 Repository 的 `Settings` → `Pages` 將 Source 設為 `main` 分支 `/ (root)`。
3. 所有資源皆採用相對路徑與 `.webp` 圖檔，並已附上 `.nojekyll`。
